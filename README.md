# YarnTime PWA

這是一個可安裝到 iPhone 主畫面的網頁 App（PWA）。

## 已完成
- 多個毛線作品分開計時
- 一次只讓一件作品計時
- 開始 / 暫停
- 分段紀錄
- 每件作品累積工時
- 工時統計
- 本機資料保存
- JSON 備份 / 匯入
- iPhone 加到主畫面後可全螢幕使用
- 切到背景或鎖螢幕後，回來仍會依開始時間正確計算

## iPhone PWA 的限制
iOS 網頁 App 不能像原生 App 一樣真正長時間在背景執行，也不能使用 Dynamic Island 做即時控制。
YarnTime 使用「開始時間戳」計算，因此即使背景暫停執行 JavaScript，回到 App 後工時仍會正確。

## 怎麼放上網
最簡單是把整個資料夾部署到任何支援 HTTPS 的靜態網站服務，例如 GitHub Pages、Cloudflare Pages、Netlify、Vercel。

PWA 的 service worker 通常需要 HTTPS（localhost 例外）。

## iPhone 安裝
1. Safari 開啟部署後的網址。
2. 點 Safari 分享按鈕。
3. 選「加入主畫面」。
4. 名稱保留 YarnTime，按「加入」。
5. 回到主畫面，會看到 YarnTime 圖示。

## 本機測試
如果電腦有 Python：
```bash
python -m http.server 8000
```
然後在瀏覽器開啟 http://localhost:8000

同一 Wi‑Fi 下，也可以用電腦的區網 IP 讓 iPhone 暫時開啟測試，但完整 PWA 安裝與 service worker 建議使用 HTTPS。

## v24 — 目前作品保留機制

### 核心邏輯拆分
- `currentProjectId`：首頁目前主要在做的作品。
- `activeProjectId`：此刻真正正在計時的作品。

### 暫停後
- 首頁作品 Hero 不消失。
- 「正在製作」改為「目前作品」。
- 「計時中」改為「已暫停」。
- 大時間改顯示作品總工時。
- 「暫停」按鈕改成「繼續製作」。
- 作品照片與作品日誌入口全部保留。

### 繼續製作
- 按「繼續製作」建立新的 Session。
- 同一件作品仍維持首頁主作品。

### 切換作品
- 開始另一件作品時：
  - 如果舊作品正在計時，先自動暫停並記錄 Session。
  - 新作品成為新的 currentProjectId。
  - 首頁 Hero 切換到新作品。

### 完成作品
- 標記完成後，如果它是目前作品，首頁主作品會清空。
- 之後可選擇其他作品繼續。

### 首頁近期作品
- 目前作品已在大卡顯示，因此近期作品不再重複顯示同一件。

## v10 — 售價透視（Price Insight）

這版重新設計「販售估價」，不再把公式算出的數字稱為「建議售價」。

### 1. 現金成本底線
計算：
- 材料成本
- 包材／其他現金成本
- 平台抽成

用途：
- 看至少要賣到多少，才不會連實際支出的成本都收不回來。
- 不把工時算進這個底線。

### 2. 目標售價
計算：
- 現金成本
- 真實總工時 × 理想時薪
- 可選的「設計／技術價值加成」
- 平台抽成

用途：
- 表示「如果希望這件作品完整涵蓋你設定的時間價值，售價大約要多少」。
- 這不是市場建議價，也不代表使用者一定要照這個價格販售。

### 3. 你的實際／預計售價
由使用者自己輸入市場售價。

YarnTime 反推：
- 扣掉平台抽成
- 扣掉材料與包材等現金成本
- 剩下的金額 ÷ 真實工時
- 得到「實際工時收入 / 小時」

並顯示：
- 理想時薪達成度 %
- 實際售價和目標售價的差額
- 中性說明，不會把低於目標價標成錯誤或虧本

### 其他調整
- 「希望時薪」改為「理想時薪」
- 「希望利潤 %」移除
- 改成可選的「設計／技術價值加成」
- 新增「手作價格不一定等於時薪公式」說明
- 保留材料、包材、平台抽成拆解
- v9 舊販售設定可繼續使用，原有資料不會消失

## v9 — 工時可信度＋販售估價

### 製作紀錄可以修正
- 每一筆自動 Session 都可以點進去編輯。

- 可刪除錯誤紀錄。
- 修改或刪除後，作品總工時會同步重新計算。

### 補登工時
- 作品內「製作紀錄」新增「＋補登」。

### 作品開始日期
- 新增 / 編輯作品時可自行設定開始日期。
- 適合把已經做一半的作品補進 YarnTime。

### 販售估價（用途選「販售」才顯示）

- 希望時薪

- 平台抽成 %
- 希望利潤 %

- 材料成本

- 包材
- 平台抽成
- 建議售價
- 若輸入實際售價，估算實際工時收入 / 小時

注意：僅為估算，不含稅務、運費與未填成本。

### 資料安全
設定頁新增：
- YarnTime 版本
- 目前網站儲存使用量
- 是否取得持久儲存
- 「提高資料保留機率」按鈕
仍建議重要資料定期匯出備份。
