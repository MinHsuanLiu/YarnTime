# YarnTime PWA v17 — New App Icon

這是一個可安裝到 iPhone 主畫面的網頁 App（PWA）。

## 已完成
- 多個毛線作品分開計時
- 一次只讓一件作品計時
- 開始 / 暫停
- 分段紀錄

- iPhone 加到主畫面後可全螢幕使用
- 切到背景或鎖螢幕後，回來仍會依開始時間正確計算

## iPhone PWA 的限制
iOS 網頁 App 不能像原生 App 一樣真正長時間在背景執行，也不能使用 Dynamic Island 做即時控制。
YarnTime 使用「開始時間戳」計算，因此即使背景暫停執行 JavaScript，回到 App 後工時仍會正確。

## 怎麼放上網
最簡單是把整個資料夾部署到任何支援 HTTPS 的靜態網站服務，例如 GitHub Pages、Cloudflare Pages、Netlify、Vercel。

PWA 的 service worker 通常需要 HTTPS（localhost 例外）。

## iPhone 安裝
1. Safari 開啟部署後的網址。
2. 點 Safari 分享按鈕。
3. 選「加入主畫面」。
4. 名稱保留 YarnTime，按「加入」。
5. 回到主畫面，會看到 YarnTime 圖示。

## 本機測試
如果電腦有 Python：
```bash
python -m http.server 8000
```
然後在瀏覽器開啟 http://localhost:8000

同一 Wi‑Fi 下，也可以用電腦的區網 IP 讓 iPhone 暫時開啟測試，但完整 PWA 安裝與 service worker 建議使用 HTTPS。

## v8 — 自動製作紀錄
核心改動：不再要求每次手作都手動新增「進度節點」。

### 自動 Session
- 按「開始」開始一段製作。
- 按「暫停」時自動新增一筆製作紀錄：
  - 日期
  - 開始時間
  - 結束時間
  - 本次製作時長
- 切換到另一件作品時，原本作品會自動暫停並留下 Session。
- 完成作品時若仍在計時，也會先自動留下最後一筆 Session。
- 舊版累積工時完整保留；逐次 Session 從 v8 開始精準累積。

### 里程碑
- 原本的「分段／進度節點」改名為「📍 記錄進度」。
- 它現在是選填的里程碑，不需要每次製作都按。
- 適合記：主體完成、袖子完成、開始收邊、完成等。
- 可附照片與備註。
- 履歷卡與回顧影片仍會優先使用里程碑照片。

### 作品資訊
每件作品可選填：
- 針號
- 毛線 / 色號
- 使用線量
- 材料成本
- 用途：自用 / 送人 / 販售 / 其他
- 織圖 / 教學來源
- 備註

## v9 — 工時可信度＋販售估價

### 製作紀錄可以修正
- 每一筆自動 Session 都可以點進去編輯。
- 可修改日期、開始時間、結束時間。
- 可刪除錯誤紀錄。
- 修改或刪除後，作品總工時會同步重新計算。
- 舊版既有工時會保留，不會因為編輯 v8 之後的 Session 而消失。

### 補登工時
- 作品內「製作紀錄」新增「＋補登」。
- 忘記開 YarnTime 時，可手動補日期 / 開始 / 結束。
- 跨過午夜時，結束時間早於開始時間會自動視為隔天。

### 忘記暫停防呆
- 單次連續計時達 4 小時以上，作品頁會顯示提醒。
- 可直接暫停後立刻開啟最後一筆 Session 修正。
- 不會強迫彈窗中斷使用。

### 作品開始日期
- 新增 / 編輯作品時可自行設定開始日期。
- 適合把已經做一半的作品補進 YarnTime。

### 販售估價（用途選「販售」才顯示）
可設定：
- 希望時薪
- 包材 / 其他成本
- 平台抽成 %
- 希望利潤 %
- 實際 / 預計售價

會自動依「真實總工時」估算：
- 材料成本
- 人工成本
- 包材
- 平台抽成
- 建議售價
- 若輸入實際售價，估算實際工時收入 / 小時

注意：僅為估算，不含稅務、運費與未填成本。

### 資料安全
設定頁新增：
- YarnTime 版本
- 目前網站儲存使用量
- 是否取得持久儲存
- 「提高資料保留機率」按鈕

## v10 — 售價透視（Price Insight）

這版重新設計「販售估價」，不再把公式算出的數字稱為「建議售價」。

### 1. 現金成本底線
計算：
- 材料成本
- 包材／其他現金成本
- 平台抽成

用途：
- 看至少要賣到多少，才不會連實際支出的成本都收不回來。
- 不把工時算進這個底線。

### 2. 目標售價
計算：
- 現金成本
- 真實總工時 × 理想時薪
- 可選的「設計／技術價值加成」
- 平台抽成

用途：
- 表示「如果希望這件作品完整涵蓋你設定的時間價值，售價大約要多少」。
- 這不是市場建議價，也不代表使用者一定要照這個價格販售。

### 3. 你的實際／預計售價
由使用者自己輸入市場售價。

YarnTime 反推：
- 扣掉平台抽成
- 扣掉材料與包材等現金成本
- 剩下的金額 ÷ 真實工時
- 得到「實際工時收入 / 小時」

並顯示：
- 理想時薪達成度 %
- 實際售價和目標售價的差額
- 中性說明，不會把低於目標價標成錯誤或虧本

### 其他調整
- 「希望時薪」改為「理想時薪」
- 「希望利潤 %」移除
- 改成可選的「設計／技術價值加成」
- 新增「手作價格不一定等於時薪公式」說明
- 保留材料、包材、平台抽成拆解
- v9 舊販售設定可繼續使用，原有資料不會消失

## v13 — 編輯視窗與返回操作修正

### 修正：作品詳情內按「編輯」跑到下面
原因：
- projectModal 在 HTML 中比 detailModal 更早。
- 舊版所有 modal 都使用同一個 z-index。
- 因此從作品詳情開編輯時，編輯視窗可能被詳情視窗壓在下面。

現在：
- 加入真正的 modal stack。
- 每開一層，自動提高 z-index。
- 編輯作品一定顯示在作品詳情上方。
- 關閉編輯後會自然回到原本的作品詳情。

### 新增：點灰色外面返回上一層
- 點 modal 白色內容外的灰色背景即可關閉目前最上層。
- 若目前是「編輯作品 → 作品詳情」兩層：
  - 點外面只關閉編輯。
  - 回到作品詳情。
- 再點作品詳情外面：
  - 才回到作品首頁。
- 不會一次把所有視窗都關掉。

### 其他
- 每次開視窗都自動回到該視窗最上方。
- 電腦測試時按 Esc 也可返回上一層。
- 開 modal 時鎖定背景頁面捲動，避免底下頁面跟著滑。

### iPhone 看到新圖示的方法
如果你已經把舊版加到主畫面，更新 GitHub 後：
1. 重新整理網站
2. 若主畫面圖示沒有立刻變，先刪掉舊的主畫面捷徑
3. 再次「加入主畫面」

這樣通常就會吃到新 icon。
