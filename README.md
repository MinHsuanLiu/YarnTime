# YarnTime PWA v8 — Auto Sessions

這是一個可安裝到 iPhone 主畫面的網頁 App（PWA）。

## 已完成
- 多個毛線作品分開計時
- 一次只讓一件作品計時
- 開始 / 暫停
- 分段紀錄
- 每件作品累積工時
- 工時統計
- 本機資料保存
- JSON 備份 / 匯入
- iPhone 加到主畫面後可全螢幕使用
- 切到背景或鎖螢幕後，回來仍會依開始時間正確計算

## iPhone PWA 的限制
iOS 網頁 App 不能像原生 App 一樣真正長時間在背景執行，也不能使用 Dynamic Island 做即時控制。
YarnTime 使用「開始時間戳」計算，因此即使背景暫停執行 JavaScript，回到 App 後工時仍會正確。

## 怎麼放上網
最簡單是把整個資料夾部署到任何支援 HTTPS 的靜態網站服務，例如 GitHub Pages、Cloudflare Pages、Netlify、Vercel。

PWA 的 service worker 通常需要 HTTPS（localhost 例外）。

## iPhone 安裝
1. Safari 開啟部署後的網址。
2. 點 Safari 分享按鈕。
3. 選「加入主畫面」。
4. 名稱保留 YarnTime，按「加入」。
5. 回到主畫面，會看到 YarnTime 圖示。

## 本機測試
如果電腦有 Python：
```bash
python -m http.server 8000
```
然後在瀏覽器開啟 http://localhost:8000

同一 Wi‑Fi 下，也可以用電腦的區網 IP 讓 iPhone 暫時開啟測試，但完整 PWA 安裝與 service worker 建議使用 HTTPS。

## v3 修正
- 修正 iPhone 點擊「新增分段」等輸入框時，Safari / PWA 自動把整個畫面放大的問題。
- 保留使用者手動縮放能力，不使用 `user-scalable=no`。

## v6 — 作品完成履歷卡
- 已完成作品會出現「生成履歷卡」。
- 自動產生 1080×1350（4:5）PNG，適合 IG / Threads 分享。
- 履歷卡會放：作品名稱、鉤針/棒針類型、開始/完成日期、作品照片、總工時、製作期間、進度紀錄次數。
- 如果有分段進度照片，會自動挑最多 3 張放在卡片下方，呈現作品成長。
- iPhone 可按「分享圖片」叫出系統分享選單；也可「下載 PNG」。
- 沒有封面照時會優先使用最後一張進度照。
- 不影響原有作品、工時、分段、照片與備份資料。

## v8 — 自動製作紀錄
核心改動：不再要求每次手作都手動新增「進度節點」。

### 自動 Session
- 按「開始」開始一段製作。
- 按「暫停」時自動新增一筆製作紀錄：
  - 日期
  - 開始時間
  - 結束時間
  - 本次製作時長
- 切換到另一件作品時，原本作品會自動暫停並留下 Session。
- 完成作品時若仍在計時，也會先自動留下最後一筆 Session。
- 舊版累積工時完整保留；逐次 Session 從 v8 開始精準累積。

### 里程碑
- 原本的「分段／進度節點」改名為「📍 記錄進度」。
- 它現在是選填的里程碑，不需要每次製作都按。
- 適合記：主體完成、袖子完成、開始收邊、完成等。
- 可附照片與備註。
- 履歷卡與回顧影片仍會優先使用里程碑照片。

### 作品資訊
每件作品可選填：
- 針號
- 毛線 / 色號
- 使用線量
- 材料成本
- 用途：自用 / 送人 / 販售 / 其他
- 織圖 / 教學來源
- 備註
作品詳細頁可以隨時「編輯」。

### 統計頁
移除沒有太大意義的「進度節點數」，改為：
- 全部累積工時
- 本月工時
- 本月手作天數
- 製作中作品數
- 本月完成作品數
- 本月平均每次製作時間
- 最近 7 天每日手作時間
- 本月最投入作品
- 作品總工時排行
